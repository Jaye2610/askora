## 核心链路备忘（一图流）

```
用户问题
  → RAGChatController ─→ RAGChatServiceImpl ─→ ChatQueueLimiter(限流)
  → StreamChatTraceRunner(Trace)
  → StreamChatPipeline
       记忆→改写→意图→[歧义澄清?短路]→[系统闲聊?短路]
       → RetrievalEngine
            MultiChannelRetrievalEngine(向量/关键词/图谱/联网)
            → 去重→RRF融合→Rerank
       → [空检索?短路]
       → Prompt 组装 → LLMService/Routing → ModelRoutingExecutor → 三态熔断降级
       → SSE 流式输出 → 落库 → finish/done
```
